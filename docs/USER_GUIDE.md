## 1. 快速开始

### 环境要求

- Python 3.12+
- uv（Python 包管理器）：`curl -LsSf https://astral.sh/uv/install.sh | sh`
- Caddy（HTTPS 反向代理）：`brew install caddy`
- FFmpeg（音频处理）：`brew install ffmpeg`
- Node.js 18+（前端构建）

### 启动服务

```bash
# 推荐：用 tmux 后台运行
tmux new-session -d -s meeting -n services "./start_domain.sh"

# 或直接运行
./start_domain.sh
```

启动后会自动运行：
- 后端 FastAPI 服务（端口 6543）
- 前端静态文件服务（端口 3456）
- Caddy HTTPS 代理（端口 8443）

### 访问地址

浏览器打开 `https://<你的域名>:8443`（首次需接受自签名证书警告）。

### 环境配置

```bash
cp .env.example .env
```

关键配置项：
- `GEMINI_API_KEY` — Gemini AI 的 API Key，用于会议分析和 AI 生成待办
- `ASR_ENGINE` — 语音识别引擎，可选 `whisper`（默认）或 `funasr`

## 2. 会议列表

首页（`/`）展示所有会议记录，按时间倒序排列。

### 功能

- **搜索** — 输入关键词搜索会议标题；勾选"搜索转录内容"可全文检索会议转录文本
- **分页** — 支持 6 / 12 / 24 条每页切换
- **新建会议** — 点击"开始录制"进入录制页面
- **会议卡片** — 每张卡片显示：
  - 会议标题（AI 自动生成或手动设置）
  - 录制时长
  - 待办数量
  - 创建时间
  - 摘要预览（如果已分析）
- **操作** — 点击卡片进入会议详情；卡片上有删除按钮（需确认）

## 3. 录制会议

进入录制页面（`/recording`）开始录制。

### 录制流程

1. 点击"开始录制"，浏览器会请求麦克风权限
2. 录制过程中实时显示：
   - 音量指示器
   - 录制时长
   - 实时转录文本（Web Speech API 和/或后端 ASR 流式识别）
3. 点击"停止录制"结束

### 音频设备选择

如果有多个麦克风，可以在录制前选择输入设备。

### 双引擎对比模式

开启"对比模式"后，同时显示两个转录引擎的结果：
- **Web Speech API**（浏览器内置）— 实时性好，需要网络
- **后端 ASR**（Whisper / FunASR）— 通过 WebSocket 流式传输，离线可用，准确度更高

### 录制后操作

录制结束后可以：
- 查看完整转录文本
- 发送完整音频到后端做最终转录（比实时转录更准确）
- 导出音频（WebM / MP3 格式）
- 进入会议详情页进一步编辑和分析

## 4. 会议详情

点击会议卡片进入详情页（`/detail/:id`）。

### 转录文本

- 按时间顺序显示所有转录片段
- 每个片段显示时间戳和说话人（如果有说话人识别数据）
- 支持点击时间戳跳转到对应音频位置

### 转录版本切换

一个会议可能有多个转录版本：
- `realtime` — 录制时的实时转录
- `final` — 录后发送完整音频的最终转录
- `web_speech` — 浏览器 Web Speech API 的结果
- `streaming` — WebSocket 流式 ASR 的结果
- `fused` — 多版本融合后的最佳结果

通过顶部的版本切换器选择查看不同版本，也可以触发"融合转录"生成综合最优版本。

### 音频播放

- 内置音频播放器，支持播放完整录音
- 支持导出为 MP3 格式下载

### AI 分析

点击"AI 分析"按钮（需配置 Gemini API Key），自动生成：
- 会议摘要
- 关键要点
- 重要决策
- 待办事项（自动提取到待办系统）

### 会议笔记

详情页底部有笔记区域，可以手动记录补充信息，自动保存。

## 5. 待办管理

待办总览页面（`/todos`）是跨会议的统一待办管理中心。

### 5.1 五种视图模式

| 视图 | 图标 | 说明 |
|------|------|------|
| 列表 | 📋 | 主视图，支持筛选、搜索、编辑、拖拽排序 |
| 看板 | 📌 | 按分类分列展示，拖拽移动分类 |
| 日历 | 📅 | 按截止日期在日历上展示，点击日期查看当天待办 |
| 分析 | 📊 | 分类统计、完成趋势等数据图表 |
| 复盘 | 🔄 | 每日回顾，总结当天完成情况 |

### 5.2 创建待办

有三种方式创建待办：

**手动创建**：点击"+ 新建待办"按钮，填写：
- 内容（必填）
- 分类（如：任务、跟进、决策）
- 优先级（高 / 中 / 低）
- 负责人
- 截止日期
- 是否需要跟进提醒

**AI 智能提取**：点击"🤖 AI 生成"按钮，粘贴会议纪要、邮件、聊天记录等文本，AI 自动识别并提取待办事项（需配置 Gemini API Key）。

**会议分析自动生成**：在会议详情页点击"AI 分析"后，分析结果中的待办会自动同步到待办系统。

### 5.3 筛选与搜索

列表视图顶部提供多维度筛选：

| 筛选项 | 选项 |
|--------|------|
| 搜索 | 全文搜索内容、负责人、分类、截止日期 |
| 状态 | 全部 / 未完成 / 已完成 |
| 跟进 | 全部 / 需要跟进 / 不需要跟进 |
| 优先级 | 全部 / 高 / 中 / 低 |
| 分类 | 全部 / 动态列出已有分类 |
| 负责人 | 全部 / 未分配 / 动态列出已有负责人 |
| 会议 | 全部 / 按来源会议筛选 |

顶部统计栏实时显示：总计、已完成、跟进中、逾期、不关心数量。

### 5.4 待办卡片操作

每个待办卡片支持以下操作：

| 按钮 | 功能 |
|------|------|
| 勾选框 | 标记完成 / 取消完成 |
| 编辑 | 修改内容、分类、优先级、负责人、截止日期、跟进状态 |
| + 子任务 | 在当前待办下添加子任务 |
| 📝 备注 | 添加进度备注（带时间戳，支持多条历史记录） |
| 标记跟进 | 标记为需要跟进（高亮显示） |
| 🔗 关联 | 关联其他待办（双向关联） |
| 查看会议 | 跳转到来源会议详情 |
| 📎 附件 | 添加需求文档或完成结果（见 5.7） |
| 🙈 不关心 | 隐藏该待办（见 5.6） |
| 删除 | 永久删除（需确认） |

### 5.5 拖拽操作

列表视图中的待办卡片支持拖拽，有三种拖拽行为：

**排序**：拖动卡片到另一个卡片的上边缘或下边缘（蓝色高亮），松开后调整顺序。

**变成子任务**：拖动卡片到另一个卡片的中央区域（黄色高亮），松开后变成目标卡片的子任务。子任务会缩进显示在父任务下方。

**不关心**：拖动卡片到列表上方的"🙈 拖到这里 = 不关心"区域（拖拽时自动出现），松开后隐藏该待办。

**子任务提升**：子任务右侧有"↑"按钮，点击可提升为独立任务。子任务也可以直接拖出到列表空白区域变回独立任务。

### 5.6 不关心（Dismiss）

会议产生的待办中，有些和你无关。"不关心"功能让你隐藏这些待办，但不删除数据。

**隐藏方式**（二选一）：
- 拖拽卡片到顶部的"🙈 拖到这里 = 不关心"区域
- 点击卡片上的"🙈 不关心"按钮

**查看被隐藏的待办**：
- 顶部统计栏会显示"不关心 N"的 badge
- 点击该 badge 切换显示/隐藏
- 被隐藏的待办以半透明样式显示，带"恢复"按钮

**恢复**：点击"恢复"按钮即可重新显示。

### 5.7 附件（需求文档与完成结果）

每个待办可以附加文档资料，分为两种类型：

**📄 需求文档**（蓝色左边框）：
- 任务的背景、需求描述、PRD 链接、设计稿等
- 例如：产品需求文档 v1、UI 设计稿链接、客户原始邮件

**✅ 完成结果**（绿色左边框）：
- 任务的交付物、代码链接、完成报告等
- 例如：PR 链接、部署地址、测试报告、交付文档

**添加附件**：
1. 点击待办卡片上的"📎 附件"按钮
2. 选择类型（需求文档 / 完成结果）
3. 填写名称和内容（支持链接、文字描述、代码片段等）
4. 点击"添加"

**查看附件**：附件显示在待办卡片中，点击"展开"查看完整内容，点击"×"删除。

### 5.8 备注系统

每个待办支持多条带时间戳的进度备注，适合记录任务推进过程：

- 点击"📝 备注"按钮快速添加一条备注
- 编辑模式下也可以添加新备注
- 备注按时间倒序显示，默认只显示最新一条
- 点击"备注 (N条)"可展开查看全部历史

## 6. 热词管理

热词页面（`/hotwords`）管理自定义词汇表，提升语音识别准确率。

适合添加的热词类型：

| 类别 | 示例 |
|------|------|
| 人名 | 张三、John |
| 公司名 | 字节跳动、Google |
| 技术术语 | Kubernetes、微服务 |
| 地名 | 硅谷、Beijing |
| 职位 | 产品经理、CTO |

热词在录制时自动生效，Whisper 和 FunASR 引擎都支持。

## 7. AI 功能

所有 AI 功能依赖 Gemini API，需要在 `.env` 中配置 `GEMINI_API_KEY`。

### 会议分析

在会议详情页点击"AI 分析"，Gemini 会分析完整转录文本，生成：
- **摘要** — 会议核心内容概述
- **关键要点** — 重要讨论点列表
- **决策** — 会议中达成的决定
- **待办** — 自动提取的行动项（含负责人、截止日期推断）

分析结果保存在会议记录中，待办自动同步到待办系统。

### AI 文本提取待办

在待办页面点击"🤖 AI 生成"，粘贴任意文本（会议纪要、邮件、聊天记录等），AI 自动识别并结构化提取待办事项，包括内容、分类、优先级、负责人等字段。

### Gemini 状态

页面顶部会显示 Gemini 连接状态，如果 API Key 未配置或无效会提示不可用。

## 8. 常见问题

### Q: 录制时没有转录文本？

- 检查浏览器是否授予了麦克风权限
- Web Speech API 需要网络连接（Chrome 使用 Google 服务器）
- 后端 ASR 需要确认服务已启动（检查 `https://<域名>:8443/health`）

### Q: AI 分析按钮不可用？

- 确认 `.env` 中配置了有效的 `GEMINI_API_KEY`
- 重启服务使配置生效
- 检查页面顶部的 Gemini 状态指示

### Q: 数据存储在哪里？

- **前端数据**：浏览器 IndexedDB（主存储），清除浏览器数据会丢失
- **后端数据**：`backend/data/meeting.db`（SQLite），音频文件在 `data/{pageId}/`
- 前后端通过 SyncService 自动同步，后端作为备份

### Q: 如何切换 ASR 引擎？

在 `.env` 中设置：
```bash
ASR_ENGINE=whisper   # faster-whisper（默认）
ASR_ENGINE=funasr    # FunASR SenseVoice
```
重启服务生效。两个引擎都支持中英文，FunASR 在中文场景下表现更好。

### Q: 如何从其他设备访问？

确保 Caddy 配置了局域网可访问的域名或 IP，其他设备通过 `https://<IP>:8443` 访问。需要在设备上接受自签名证书。

### Q: 待办的特殊 pageId 是什么意思？

| pageId | 含义 |
|--------|------|
| `_manual_` | 手动创建的待办 |
| `_ai_generated_` | AI 从文本提取的待办 |
| 其他 UUID | 来自对应会议的 AI 分析 |
